# south-paw-superiority
Item Stock Program with PHP base (idk)

How to use

1. Download XAMPP and then start the Apache and Mysql.
2. Download the ZIP files of south-paw-superiority
3. Unzip the files
4. Copy and paste the files to a new folder called "stockbarang" make sure the folder is in: Local disk(C:) > xampp > htdocs
5. Open in your browser: "localhost/phpmyadmin"
6. Create a new database called stockbarang and then import "Stockbarang.sql"
7. Now you can open in your browser: "localhost/stockbarang/login.php"
